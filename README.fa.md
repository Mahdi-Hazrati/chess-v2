# Chess V2 — راهنمای راه‌اندازی

نسخهٔ ۱.۲ وبسایت، با قوانین نسخهٔ ۳. طراحی ساده و کلاسیک، صفحهٔ شش‌ضلعی ۱۲۷ خانه‌ای و ۱۷ نوع مهره. هدف گرفتن شاه حریف است؛ کیش‌ومات وجود ندارد.

## اجرای محلی

Node.js نسخهٔ ۲۰ یا بالاتر نصب کنید. ZIP را استخراج کنید، ترمینال را در پوشهٔ `chess-v2` باز کنید و اجرا کنید:

```sh
npm run preview
```

آدرس `http://127.0.0.1:4173/` را باز کنید. نصب پکیج و بیلد لازم نیست. فایل HTML را مستقیم باز نکنید؛ ماژول‌ها و ربات به HTTP نیاز دارند.

## استقرار روی GitHub Pages

۱. یک ریپوی گیت‌هاب دارای امکان Pages بسازید. برای مسیر ساده از ریپوی عمومی استفاده کنید.
۲. محتوای داخل پوشهٔ `chess-v2` را در ریشهٔ ریپو قرار دهید، شامل پوشهٔ مخفی `.github`.
۳. فایل‌ها را روی شاخهٔ `main` پوش کنید.
۴. در Settings → Pages، گزینهٔ Source را روی GitHub Actions بگذارید.
۵. در Actions، workflow با نام Verify and deploy Chess V2 را اجرا کنید.
۶. بعد از موفقیت هر دو job، لینک سایت در محیط github-pages نمایش داده می‌شود. پوش‌های بعدی به main خودکار منتشر می‌شوند.

فقط پوشهٔ `dist` منتشر می‌شود. نیازی به سرور، دیتابیس، کلید API یا تنظیم base URL نیست. اگر نام شاخه متفاوت است، فیلتر شاخه‌ها را در `.github/workflows/pages.yml` تغییر دهید. این بسته آمادهٔ استقرار است؛ هنوز در اکانت گیت‌هاب شما منتشر نشده است.

## شروع بازی

- **Play:** روی مهره و سپس خانهٔ مجاز کلیک کنید. سفید شروع می‌کند. شاه قابل گرفتن است.
- **Learn:** آموزش تعاملی ۱۶ مرحله‌ای، با راهنمای حرکت و بررسی پاسخ. بازی اصلی محفوظ می‌ماند و با Return to my game برمی‌گردد.
- **Pieces:** معرفی تمام مهره‌ها و حرکتشان.
- **Rules & pieces:** قوانین کامل و قابل جست‌وجو، شامل ترکیب، ذخیره، زنبور، مرکز، دیوار، دروازه، گارد و شرایط مساوی.
- **Watch bots play:** تماشای بازی دو ربات؛ One bot action فقط یک اکشن انجام می‌دهد.
- **Files & tools:** ذخیره و بارگذاری فایل بازی، رابط ربات و آزمون خودکار سه بازی مستقل.
- **Focus board:** تمرکز روی صفحه. Flip جهت را عوض می‌کند؛ All tokens نمایش مهره‌ها را با نسخهٔ چاپی یکسان می‌کند.

ذخیره در مرورگر خودتان است؛ برای نگهداری مطمئن از بازی فایل خروجی بگیرید. پاک کردن داده‌های مرورگر ذخیره‌ها را حذف می‌کند. حساب کاربری و همگام‌سازی ابری وجود ندارد.

## نسخهٔ واقعی و دفترچه

- `dist/Chess-V2-Rulebook.pdf`: دفترچهٔ کامل ۱۰ صفحه‌ای انگلیسی.
- `dist/Chess-V2-Print-and-Play.pdf`: بورد A3، چهار تکهٔ A4، توکن‌های دو طرف، نشانگرها، جدول چیدمان و برگهٔ ثبت وضعیت.

با مقیاس ۱۰۰٪ چاپ کنید و خط ۵۰ میلی‌متری را اندازه بگیرید. برای A4 چهار مربع را ببرید و شماره‌های ۱ و ۲ را بالا، ۳ و ۴ را پایین بچسبانید. مهره‌های عادی را می‌توانید از شطرنج واقعی بردارید؛ نقش‌های تازه با دیسک‌های ساده و کد مشخص بازی می‌شوند. ترکیب‌ها و مسافر Courier روی برگه ثبت می‌شوند.

## توسعه و کنترل کیفیت

```sh
npm run verify
npm run docs
```

دستور اول ۴۱ تست و کنترل فایل‌ها، لینک‌ها و نحو جاوااسکریپت را اجرا می‌کند. دستور دوم راهنمای HTML را می‌سازد. برای بازتولید PDF، Python و ReportLab لازم است؛ دستورات و معماری کامل در README.md آمده است. برای استقرار، PDFها از قبل آماده‌اند.

قدرت ربات تمرینی است و توازن رقابتی نیازمند بازی‌تستی بیشتر است. بازی دونفره روی یک دستگاه پشتیبانی می‌شود؛ مولتی‌پلیر آنلاین در این نسخه وجود ندارد. موتورهای شطرنج استاندارد بدون پیاده‌سازی این قوانین نمی‌توانند بازی کنند؛ رابط توسعهٔ ربات در `dist/BOT-PROTOCOL.md` توضیح داده شده است.
